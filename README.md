# Hondana

**Hondana** to aplikacja do zarządzania Twoją wirtualną biblioteką japońskich tekstów – manga, artykuły, etykiety etc.

## 🚀 Funkcje:
- Dodawanie i porządkowanie materiałów z opcją tagowania
- Integracja z zewnętrznymi tłumaczeniami i słownikami
- Intuicyjny interfejs użytkownika

## 🛠️ Technologie:
- Back‑end: Spring(Java)

## 🔧 Instalacja
1. `git clone https://github.com/S4ris/Hondana.git`
2. `cd Hondana`
3. `npm install`
4. `npm start`
5. Wejdź na `http://localhost:3000/`

## 🎯 Wsparcie rozwoju
- Dodatek tłumaczeń: REST API / moduł integracji ze słownikami (np. Jisho)
- Eksport danych do CSV/PDF
- Utworzenie zewnętrznej bazy danych
- Dodanie Frontendu
